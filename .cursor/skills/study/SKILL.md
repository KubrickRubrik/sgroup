# Обязательный пример «Изучено»

Скопируй этот шаблон в свой скилл. Путь к скиллу указывается в настройках Syn3 (активный профиль), поле «Путь к скиллу «Изучено»». Модель — «Модель агента карты».

Syn3 передаёт выбранные пункты родительского ревью. Команды глубины нет. Не переспрашивай область.

---

Разбери выбранные пункты ревью человеческим языком. Файлы не меняй: ни правок, ни коммитов, ни пуша.

## Шапка

Это условие обязательное. Без него «Изучено» из меню Syn3 теряет границы выборки.

Разбираются только пункты из блока «Пункты». Не ищи дефекты вне них.

Команды `/rl`, `/rm`, `/rd` в запуске нет. Глубину не выбирай и не пиши. Разбор — кейс воспроизведения, примеры и контекст по каждому пункту. Syn3 сам пишет первую строку файла.

Не пиши строку `H:N | M:N | L:N`. Не пиши таблицу. Не пиши `branch`, `changes`, `rl`, `rm`, `rd`.

Если в запуске есть блок `Host-diff` / `--- host-diff ---`, это вся область. Локальный git и рабочее дерево не читай. Команды git не запускай. Пути «Где» ищи внутри host-diff.

Если host-diff нет, можно открывать файлы из строк «Где».

## Тело

Язык — язык пользователя. Запуск от Syn3 — русский.

Выше первого якоря ничего не пиши. У каждого выбранного пункта свой блок. Якорь — первая строка, ровно `H:1`, `M:2` или `L:4`: буква уровня и номер пункта из ревью, без нового отсчёта с 1.

Дальше, обычным текстом:

- что сломано, своими словами, шире лаконичной строки ревью;
- кейс воспроизведения: шаги, вход, что видно;
- один-два конкретных примера;
- что ещё вокруг этого места, если без этого кейс непонятен.

Имя из кода пиши markdown-кодом, чтобы оно отличалось от текста. В строке — обратные кавычки: `media/map.js`, `reviewNeurofixButton`. Несколько строк — блок: пустая строка, строка из трёх обратных кавычек, код, снова строка из трёх обратных кавычек, пустая строка.

Не проси подтверждения. Не предлагай патч.

```markdown
H:1

Кнопка искры на чужой ветке не открывает меню, хотя разбор пункта можно собрать по diff.

Кейс: открыть карту ревью на ветке, которая не совпадает с чекаутом, и нажать искру у чипа «Ревью 1». Меню не появляется.

Пример: ревью ветки `feature/map`, локально `main`. Пункт про `reviewNeurofixButton` в `media/map.js`.

L:4

Подпись чипа не показывает, какой пункт разбирается, если в тексте нет якоря.

Кейс: запустить «Изучено» по L:4 и открыть файл. Первая строка пункта должна быть `L:4`.

Пример: выборка `L:4` из ревью 1, ветка `branch`.
```
