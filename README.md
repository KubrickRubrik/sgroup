# SynGroup

Расширение SynGroup для VS Code и Cursor. В интерфейсе лейбл — **SGroup**. Помечает файлы и папки маркерами, чтобы держать рядом сущности, близкие по смыслу, даже если по алфавиту они лежат в разных частях проекта.

Стандартный Explorer остаётся как есть. Рядом с ним появляется панель **SGroup**, где помеченные файлы и папки собраны в группы по маркерам.

## Возможности

- **Пометить:** правый клик по файлу или папке в Explorer → `Mark…`. Можно выбрать несколько элементов сразу.
- **Группы по маркерам** с цветом и иконкой. Порядок групп меняется стрелками или перетаскиванием группы на группу.
- **Помеченные папки** раскрываются в реальное содержимое.
- **Перетаскивание:** из Explorer на группу — пометить; между группами — сменить маркер.
- **Переименование** (`F2` в панели) через `WorkspaceEdit`. Языковые расширения, например Dart, обновляют импорты так же, как при переименовании в Explorer.
- **Маркеры не теряются** при переименовании файлов и папок в редакторе.
- **Отсутствующие файлы** (переименованы в терминале, удалены, другая ветка) показываются с ⚠. Действие `Relink to File…` предлагает файлы с тем же именем.
- **Цвета** у помеченных файлов в стандартном Explorer.
- **Подсветка активного файла** в панели, если он помечен.
- **Карта групп (Map)** — отдельная компактная боковая панель с прозрачным фоном (см. ниже).

## Карта групп

В боковой панели Explorer появляются две секции:

1. **SGroup** — дерево с группами (помечать, переименовывать, drag & drop).
2. **SGroup Map** — компактная карта: цветные полосы, «чипсы» / список, свёрнутая группа → ряд точек.

Activity Bar не нужна. Если карты не видно: `Cmd+Shift+P` → **SGroup: Open Map**, или кнопка карты в заголовке дерева SGroup.

- Клик — открыть файл, `Alt+Click` — показать в Explorer.
- Правый клик — нативное меню: переименовать, снять маркер, перепривязать; на заголовке группы — изменить, переставить, удалить маркер.
- Кнопка в заголовке переключает вид «чипсы / список».
- Активный файл подсвечивается рамкой.

Размер шрифта зависит от уровня: группа, подгруппа, папка, файл. Внутри группы сначала идут папки. Базовый размер берётся из настроек редактора и масштабируется в **SGroup: Open Settings**.

**Карта колонкой вплотную к Explorer.** Кнопка `Toggle Map Column Beside Explorer` в заголовке SGroup или SGroup Map (или `Cmd+Shift+P` → **SGroup: Toggle Map Column Beside Explorer**). Получится раскладка:

```
[ Explorer ][ SGroup Map ][ Редактор ]
```

- Это узкая колонка у левого края области редактора, шириной `sgroup.map.columnWidth` (по умолчанию 260 px); ширину можно подтянуть мышью.
- Колонка закреплена: новые файлы в неё не открываются, клик по карте открывает файл в колонке с кодом.
- Открытые вкладки остаются на своих местах, Terminal и Problems не трогаются.
- После перезапуска окна колонка восстанавливается. Повторное нажатие кнопки закрывает её.
- Над картой есть полоска с одной вкладкой «SGroup Map» — это ограничение колонок редактора.

**Альтернатива — вторичная боковая колонка (справа от редактора).** Кнопка `Move Map…` → **New Secondary Side Bar Entry**.

## Хранение и обмен с командой

Маркеры и внешний вид карты лежат в `.sgroup/sgroup.json`. Закоммить файл — и у всей команды будут те же группы и размеры шрифта. Старые `.vgroup/vgroup.json` и `.vscode/vgroup.json` при первом запуске переносятся автоматически.

```json
{
  "version": 1,
  "pages": {
    "map": {
      "name": "Карта",
      "kind": "files",
      "order": 1,
      "layout": "chips",
      "groupsLayout": "flow",
      "collapsed": {}
    }
  },
  "markers": {
    "ads": { "label": "Реклама", "color": "charts.orange", "order": 1, "page": "map" }
  },
  "items": {
    "lib/ui/widgets/book_info_ad_banner_section.dart": ["ads"],
    "lib/utils/ads_config_ids.dart": ["ads"]
  },
  "notes": {
    "note-1": { "markerId": "tips", "text": "См. https://example.com", "order": 1 }
  },
  "appearance": {
    "fontGroup": 1.15,
    "fontSubgroup": 1.05,
    "fontFolder": 0.95,
    "fontFile": 0.9,
    "fontScale": 1,
    "gradientDirection": 0,
    "labelSaturation": 20
  }
}
```

До трёх страниц (`pages`): `kind` — `files` (группы с файлами) или `notes` (группы с текстовыми записями). Корневые маркеры ссылаются на страницу полем `page`. Записи лежат в `notes`. Старый файл без `pages` при открытии получает одну страницу «Карта».

Файл можно править руками, панель обновится автоматически. Цвет — любой id цвета темы, например `charts.red`, `charts.blue`, `terminal.ansiCyan`. Внешний вид также открывается командой **SGroup: Open Settings**. Страницы создаются в меню ⋯ на карте.

## Настройки

| Настройка | По умолчанию | Описание |
|---|---|---|
| `sgroup.showDecorations` | `true` | Цвета помеченных файлов в стандартном Explorer |
| `sgroup.map.columnWidth` | `260` | Ширина колонки карты рядом с Explorer, px |

Размеры шрифта карты, направление градиента карточки группы и насыщенность имён в Explorer задаются во вкладке **SGroup: Open Settings** и пишутся в `appearance` внутри `.sgroup/sgroup.json`. `gradientDirection`: 0 — угол по умолчанию (135°), 100 — тот же угол после полного оборота.
## Ограничения

- Используется только первая папка workspace (multi-root пока не поддерживается).
- Переименование — через поле ввода вверху окна: API деревьев расширений не умеет редактировать имя прямо в строке.
- Переименования вне редактора (`git mv`, терминал) не отслеживаются: такие элементы станут «missing», их можно перепривязать.

## Разработка

```bash
npm install
npm run compile      # сборка в dist/
npm run watch        # пересборка при изменениях
npm run package      # проверка типов + production-сборка + sgroup-<version>.vsix
```

F5 открывает окно Extension Development Host с подключённым расширением.

Установка `.vsix`:

```bash
cursor-ide --install-extension sgroup-0.7.0.vsix
code --install-extension sgroup-0.7.0.vsix
```
