# VGroup

Расширение для VS Code и Cursor. Помечает файлы и папки маркерами, чтобы держать рядом сущности, близкие по смыслу, даже если по алфавиту они лежат в разных частях проекта.

Стандартный Explorer остаётся как есть. Рядом с ним появляется панель **VGroup**, где помеченные файлы и папки собраны в группы по маркерам.

## Возможности

- **Пометить:** правый клик по файлу или папке в Explorer → `Mark…`. Можно выбрать несколько элементов сразу.
- **Группы по маркерам** с цветом и бейджем. Порядок групп меняется стрелками или перетаскиванием группы на группу.
- **Помеченные папки** раскрываются в реальное содержимое.
- **Перетаскивание:** из Explorer на группу — пометить; между группами — сменить маркер.
- **Переименование** (`F2` в панели) через `WorkspaceEdit`. Языковые расширения, например Dart, обновляют импорты так же, как при переименовании в Explorer.
- **Маркеры не теряются** при переименовании файлов и папок в редакторе.
- **Отсутствующие файлы** (переименованы в терминале, удалены, другая ветка) показываются с ⚠. Действие `Relink to File…` предлагает файлы с тем же именем.
- **Бейджи и цвета** у помеченных файлов в стандартном Explorer.
- **Подсветка активного файла** в панели, если он помечен.
- **Карта групп (Map)** — отдельная компактная боковая панель с прозрачным фоном (см. ниже).

## Карта групп

В боковой панели Explorer появляются две секции:

1. **VGroup** — дерево с группами (помечать, переименовывать, drag & drop).
2. **VGroup Map** — компактная карта: цветные полосы, «чипсы» / список, свёрнутая группа → ряд точек.

Activity Bar не нужна. Если карты не видно: `Cmd+Shift+P` → **VGroup: Open Map**, или кнопка карты в заголовке дерева VGroup.

- Клик — открыть файл, `Alt+Click` — показать в Explorer.
- Правый клик — нативное меню: переименовать, снять маркер, перепривязать; на заголовке группы — изменить, переставить, удалить маркер.
- Кнопка в заголовке переключает вид «чипсы / список».
- Активный файл подсвечивается рамкой.

Размер шрифта зависит от уровня: название группы крупнее, папки чуть мельче, файлы ещё мельче. Внутри группы сначала идут папки. Базовый размер берётся из настроек редактора.

**Карта колонкой вплотную к Explorer.** Кнопка `Toggle Map Column Beside Explorer` в заголовке VGroup или VGroup Map (или `Cmd+Shift+P` → **VGroup: Toggle Map Column Beside Explorer**). Получится раскладка:

```
[ Explorer ][ VGroup Map ][ Редактор ]
```

- Это узкая колонка у левого края области редактора, шириной `vgroup.map.columnWidth` (по умолчанию 260 px); ширину можно подтянуть мышью.
- Колонка закреплена: новые файлы в неё не открываются, клик по карте открывает файл в колонке с кодом.
- Открытые вкладки остаются на своих местах, Terminal и Problems не трогаются.
- После перезапуска окна колонка восстанавливается. Повторное нажатие кнопки закрывает её.
- Над картой есть полоска с одной вкладкой «VGroup Map» — это ограничение колонок редактора.

**Альтернатива — вторичная боковая колонка (справа от редактора).** Кнопка `Move Map…` → **New Secondary Side Bar Entry**.

## Хранение и обмен с командой

Маркеры лежат в `.vscode/vgroup.json` (путь задаётся настройкой `vgroup.configPath`). Закоммить файл — и у всей команды будут те же группы.

```json
{
  "version": 1,
  "markers": {
    "ads": { "label": "Реклама", "color": "charts.orange", "badge": "AD", "order": 1 }
  },
  "items": {
    "lib/ui/widgets/book_info_ad_banner_section.dart": ["ads"],
    "lib/utils/ads_config_ids.dart": ["ads"]
  }
}
```

Файл можно править руками, панель обновится автоматически. Цвет — любой id цвета темы, например `charts.red`, `charts.blue`, `terminal.ansiCyan`.

## Настройки

| Настройка | По умолчанию | Описание |
|---|---|---|
| `vgroup.configPath` | `.vscode/vgroup.json` | Путь к файлу маркеров относительно корня проекта |
| `vgroup.revealActiveFile` | `true` | Подсвечивать активный файл в панели |
| `vgroup.showDecorations` | `true` | Бейджи и цвета в стандартном Explorer |
| `vgroup.map.columnWidth` | `260` | Ширина колонки карты рядом с Explorer, px |
## Ограничения

- Используется только первая папка workspace (multi-root пока не поддерживается).
- Переименование — через поле ввода вверху окна: API деревьев расширений не умеет редактировать имя прямо в строке.
- Переименования вне редактора (`git mv`, терминал) не отслеживаются: такие элементы станут «missing», их можно перепривязать.

## Разработка

```bash
npm install
npm run compile      # сборка в dist/
npm run watch        # пересборка при изменениях
npm run package      # проверка типов + production-сборка + vgroup-<version>.vsix
```

F5 открывает окно Extension Development Host с подключённым расширением.

Установка `.vsix`:

```bash
cursor-ide --install-extension vgroup-0.7.0.vsix
code --install-extension vgroup-0.7.0.vsix
```
