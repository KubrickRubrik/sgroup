# Как подключить скилл тега Figma

Скилл находит слой по тегу JSON Metadata Tagger и возвращает ссылку. Даты создания, обновления и редактирования попадают в ответ только если Figma их отдала.

## 1. Тег на слое

1. В файле Figma поставь плагин JSON Metadata Tagger.
2. Назначь тег нужному слою. Плагин пишет его в shared plugin data: namespace `icon_tagger`, ключ `tags`, значение — JSON-массив строк.

## 2. Карта Figma

1. Открой настройки страницы Figma.
2. Вставь персональный токен. Ему нужно право File content: Read. Этот токен нужен вкладке API. MCP его не берёт и не печатает.
3. Добавь ссылку на файл. В список попадёт ключ файла.
4. Скачай обязательный скилл кнопкой загрузки. Выбери только папку: внутрь ляжет каталог `figma-tag` с `SKILL.md`, `lookup.js` и `scan.js`.
5. В поле «Путь к скиллу» укажи `SKILL.md` или папку `figma-tag`.
6. «Модель агента карты» можно оставить пустой: тогда у агента будет модель по умолчанию. «Печать размышления» и «Вызовы инструментов» управляют только текстом в терминале.

Токен остаётся в секретах редактора.

## 3. Вход MCP для карты

Вход в Figma в чате Cursor карта не использует. «Формировать» → MCP запускает отдельный `agent --print`, и у него своя сессия.

1. В `~/.cursor/mcp.json` рядом с остальными серверами добавь:

```json
"Figma": {
  "url": "https://mcp.figma.com/mcp"
}
```

2. Открой терминал IDE (`` Ctrl+` `` или Terminal → New Terminal). Это не запуск карты.
3. Выполни `agent mcp login Figma`. В браузере войди в тот аккаунт Figma, которому видны файлы карты.
4. Проверь `agent mcp list`: Figma должен быть подключён.

Пока Figma в этом списке нет, агент карты отвечает «Figma MCP не авторизован», даже если в чате аккаунт уже вошёл. В сам `agent --print` войти нельзя: он не открывает браузер. Вход делается один раз командой выше, дальше карта берёт сохранённую сессию.

Перед обходом открой Figma.app и вкладки файлов из настроек карты. Расширение эти вкладки само не открывает, и теги находятся, только пока файлы открыты.

Если `agent mcp login Figma` отвечает Forbidden, CLI не прошёл OAuth. Тогда собирай теги вкладкой API.
